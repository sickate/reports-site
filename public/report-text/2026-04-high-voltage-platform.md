Market Lens
原图真正表达的是四种定价方式
先别把这张图理解成严格线性的上下游顺序。它更像是同一条 800V 升级主线，在不同公司类型上的四种投影方式。

Long Option
高弹性期权
市场买的是第三代功率器件渗透率与估值弹性，赔率高，但更依赖 800V 放量节奏。
NVTSNavitas Semiconductor
纯第三代功率半导体公司，GaNFast GaN 功率 IC + GeneSiC SiC；汽车侧落点是 OBC、HV-LV DC/DC、高压电源转换。

POWIPower Integrations
强项是高压电源转换与驱动，SCALE EV 车规门极驱动支持 SiC MOSFET / IGBT，典型卡位在牵引逆变器高压功率级。

Execution Breadth
平台型、覆盖广
市场买的是平台广度和多点兑现能力，一旦 800V 渗透，上游多个 socket 同时受益。
ADIAnalog Devices
核心覆盖 BMS、电流/电压采样、隔离与信号链，偏“控制精度”和“安全性”收益。

IFXInfineon Technologies
大平台功率半导体 + 车规 MCU / 控制玩家，覆盖电驱、OBC、DC/DC、功率器件，是 800V 渗透的宽受益者。

RENESASRenesas Electronics
EV/HEV 方案里直接覆盖 traction inverter、chargers、fast charging、battery management，偏 MCU / 控制 + 功率 + 系统方案。

TXNTexas Instruments
覆盖牵引逆变器、BMS、隔离 / 检测 / 控制，并有 800V SiC 牵引逆变器参考设计。

Socket & Position
卡位明确、单车价值量抬升
市场买的是明确卡位和单车价值量提升，高压架构越复杂，这类公司越容易放大 ASP。
MPWRMonolithic Power Systems
更像电源管理 + 隔离 + BMS + 栅驱的 socket 型公司，覆盖 traction inverter、OBC、DC/DC、DC fast charging。

AOSLAlpha and Omega Semiconductor
MOSFET / IGBT / SiC / Power IC 平台，官方明确把 EV Powertrain 指向主驱逆变器 + OBC，并同时适配 400V / 800V 架构。

Structural Shift
架构升级受益者
市场买的是系统级电源网络重构，而不是单颗器件放量；兑现路径更偏整车平台升级和总成架构迁移。
VICRVicor
高密度电源模块 / PDN 架构公司，重点落在 400V / 800V 兼容快充、800V / 400V 到 48V 的电源配送网络、减重和体积优化。

DELTADelta Electronics
系统级电力电子集成商，覆盖 OBC、DC/DC、牵引逆变器、牵引电机和 X-in-1 集成产品。

Real Chain
按真实产业链重排，高压平台升级是三层结构
如果真正按产业链来排，这些公司不应混成一张“顺序图”。更准确的框架，是功率器件、模拟控制、系统架构三层同时抬升。

01
功率器件 / 功率级
SiC / GaN / IGBT / MOSFET / Gate Driver，决定效率、温升与功率密度。

02
模拟控制 / BMS / 隔离
采样、隔离、栅驱、控制、MCU、BMS，决定控制精度与安全边界。

03
系统级电源架构 / 集成总成
OBC、DC/DC、逆变器、X-in-1、800V↔400V↔48V 配电架构，决定集成度与整车电能流。

环节一：功率器件 / 功率级
决定高压平台的效率、温升与功率密度

核心看点
SiC / GaN / IGBT / MOSFET / Gate Driver

NVTS海外代表
第三代功率半导体弹性标的，GaN 指向 400V，SiC 指向 800V 及以上平台。

POWI海外代表
高压电源转换与车规门极驱动切入牵引逆变器功率级。

IFX海外代表

功能映射结论

交易主线
最硬的主线仍是 SiC 器件 / 模块，重点看时代电气、斯达半导。
