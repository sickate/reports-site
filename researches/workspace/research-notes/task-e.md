## Findings

- 近90天内共14家机构给出评级，其中买入11家、增持3家，无减持或卖出评级；机构目标均价56.53元。[2][8]
- 群益证券赵旭东给出最高目标价60.0元（增持），基于2026年PE约55倍，对应归母净利润10.0亿元预测。[3]
- 国泰海通肖隽翀维持增持评级，目标价58.30元，基于可比公司2026年PE均值56.44倍给予55倍PE。[1]
- 中银证券姜帆给予买入评级，预测2026年归母净利润9.5亿元，目标价42.34元（对应42.41倍PE），为机构中较保守的估值。[4]
- 中国银河证券给予买入评级，目标价51.3元，对应2026/2027年PE为47.9/36.4倍。[10]
- 上海证券方晨维持增持评级，预测2026年归母净利润10.72亿元，对应PE 43.07倍。[6]
- 2025年半导体业务收入20.86亿元占总营收57%，CMP抛光垫收入10.91亿元同比增52.34%，已成为绝对核心利润来源。[1][3]
- 主要风险：传统打印耗材业务收入同比下滑12.97%，芯片设计板块单价下行；高端光刻胶等新业务尚未盈利且需持续投入。[7]
- 公司出售子公司触发约2.44亿元商誉一次性减值，预计对2026年净利润造成约1.99亿元非经常性亏损。[9]
- 当前PE(TTM)约65倍处于历史高位区间，近5日主力资金持续净流出，技术面处于箱体震荡偏弱格局。[8][11]

## Deep Read Notes

### Source [1]: 国泰海通证券 鼎龙股份2025年报&2026Q1业绩点评
Key data: 2025年营收36.60亿元(+9.66%)，归母净利润7.20亿元(+38.32%)，扣非净利6.78亿元(+44.53%)；2026Q1预告归母净利润2.4-2.6亿元(+70%-84%)；EPS预测2026E/2027E/2028E为1.06/1.37/1.77元
Key insight: 给予55倍PE估值（基于可比公司均值56.44倍），目标价58.30元；半导体板块收入占比57%已成为绝对主力
Useful for: 最新盈利预测基准、估值方法论参考、半导体业务拆分数据

### Source [3]: 群益证券 上调目标价至60元
Key data: 2026-2028年归母净利润预测10.0/13.2/15.9亿元（+39%/+32%/+20%）；毛利率50.9%（+4.0pcts）；CMP抛光垫单月销量首次突破4万片
Key insight: 潜江二期年产300吨光刻胶产线主体完成，20款产品已验证、3款进入批量供应，是中长期增长新引擎
Useful for: 光刻胶产业化进度追踪、最乐观估值锚定

### Source [7]: 新浪财经 新老动能转换多维考验分析
Key data: 传统耗材收入同比-12.97%；芯片设计板块单价下行；研发支出5.19亿元占营收14.19%；新建产线折旧压力增大
Key insight: 业绩增长高度依赖半导体单一板块拉动，传统业务陷入存量博弈，财务费用同比激增321.38%（因可转债利息和汇兑损失）
Useful for: 构建反方观点的核心论据——增长结构单一、费用端承压、新产品尚未盈利

### Source [9]: 东方财富 商誉减值分析
Key data: 出售子公司股权转让款约1.93亿元，产生约0.45亿元收益；但账面3.54亿元商誉需一次性计提，预计减值约2.44亿元，净亏损约1.99亿元
Key insight: 该笔非经常性损失将拖累2026年报表净利润，但不影响扣非净利润；市场可能已部分消化该预期
Useful for: 评估2026年实际净利润可能低于机构预测值的风险
