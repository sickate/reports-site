## Findings

- 2025年前五大客户合计销售占比仅24.12%，第一大客户占10.87%，客户集中度处于中等偏低水平，分散化较好。 [1]
- 2025年前五大供应商合计采购占比仅16.08%，第一大供应商占4.84%，供应商依赖度极低，供应链高度分散。 [1]
- CMP抛光垫客户涵盖长江存储、合肥长鑫、中芯国际、华虹宏力、华力微电子、士兰微、广州粤芯等国内所有主流晶圆厂。 [2]
- 显示材料客户包括京东方、TCL华星光电、维信诺、天马等主流面板厂，已成为部分客户YPI/PSPI产品的第一供应商。 [6]
- 公司已实现CMP抛光垫三大核心原材料（预聚体、微球、缓冲垫）全部自主量产，成为全球供应链最完整的CMP抛光垫供应商。 [2]
- 在国内CMP抛光垫市场，鼎龙股份国产化替代率已达约80%，打破了美国陶氏化学（DOW）此前全球79%市占率的独家垄断。 [3]
- 公司CMP抛光垫已在某主流外资逻辑芯片厂商实现小批量供货，标志着从纯内需向国际市场突破。 [3]
- 半导体材料行业认证壁垒极高，下游客户一旦完成验证通常不会轻易更换供应商，形成强客户粘性护城河。 [2]
- 2025年半导体业务收入20.86亿元（占总收入57%），其中CMP抛光垫10.91亿元，显示材料5.44亿元，抛光液/清洗液2.94亿元。 [4]
- 全球CMP抛光垫市场此前由美国DOW一家垄断79%份额，鼎龙作为国产唯一替代者，对国内晶圆厂客户拥有较强议价权基础。 [8]

## Deep Read Notes

### Source [1]: 鼎龙股份(300054) 经营分析 - 同花顺
Key data: 2025年报前五大客户占比24.12%（第一大10.87%、第二大5.03%、第三大2.95%、第四大2.80%、第五大2.47%）；前五大供应商占比16.08%（第一大4.84%、第二大4.40%、第三大2.41%、第四大2.36%、第五大2.07%）。客户和供应商名称均未披露。
Key insight: 客户集中度和供应商集中度均处于较低水平，公司不存在严重的大客户依赖或单一供应商风险，这在半导体材料行业中较为少见，反映出公司产品线多元化（半导体+打印耗材）的优势。
Useful for: 定量评估客户/供应商集中度风险，与同行业公司对比。

### Source [2]: 鼎龙股份：一家半导体材料公司为何要去香港上市
Key data: 详细列出CMP抛光垫客户名单（长江存储、合肥长鑫、中芯国际、华虹宏力、华力微电子、士兰微、广州粤芯）和显示材料客户（京东方、TCL华星光电）；三大核心原材料自主量产（预聚体、微球、缓冲垫）；海外市场尚处于小批量阶段。
Key insight: 公司已完成国内所有主流晶圆厂的CMP抛光垫认证导入，客户覆盖率极高，但从小批量到大规模商业化仍有距离，海外拓展存在不确定性。半导体材料的高认证壁垒形成强客户粘性。
Useful for: 定性分析客户质量、认证壁垒带来的议价权、海外扩张风险。

### Source [3]: CMP抛光垫产品反向供货外资厂商 - 湖北省经信厅
Key data: 国产化替代率近80%；全球唯一同时提供CMP抛光垫、抛光液、清洗液和钻石碟四种CMP材料的系统供应商；研发投入约占营收12%；1300余项专利。
Key insight: 鼎龙从"被替代者"转变为"替代者"再到"反向供货外资"，议价权逻辑清晰——作为国内唯一全制程CMP抛光垫供应商，在国产替代大趋势下对国内晶圆厂客户拥有较强的定价权，但对海外客户仍处于导入期，议价权有限。
Useful for: 竞争格局分析、议价权评估、国产替代逻辑论证。
