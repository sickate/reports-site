## Findings

- 三花智控制冷零部件全球龙头：空调四通换向阀份额>55%（有数据点为58.7%），空调电子膨胀阀>60%，空调电磁阀>50%，均为全球第一 [2][8]
- 制冷元器件行业集中度极高，四通换向阀 CR3≈98%，电子膨胀阀 CR3≈96%，形成三花+盾安+不二工机寡头格局，已高度出清 [6]
- 盾安环境四通阀、截止阀继续稳居行业第一；四通阀市占率从2018年35.9%提升至2022年前三季度45.5%，阀件合计销量跃居行业第一，在电子膨胀阀仍落后三花 [4][9]
- 2024年中国新能源汽车热管理电子膨胀阀销量突破2700万只，同比增速>46%；整个中国NEV热管理系统销售规模达771亿元（内销676亿，同比+20%），呈"二八分"内外销结构 [1]
- 三花智控2024年汽车零部件业务营收113.86亿元，毛利率27.64%；NEV热管理销量6952万只，同比+11.2%；全年总营收279.47亿元，归母净利30.99亿元 [3]
- 盾安环境2024年汽车热管理业务营收8.12亿元，同比+71.66%（其中并购大创贡献0.51亿）；全年总营收126.78亿，归母净利10.45亿（+41.58%），综合毛利率18.22%（同比-4.34pct，低于三花27.47%约9pct） [4][5]
- 体量对比：盾安NEV热管理营收仅为三花汽零业务的约7%（8.12亿 vs 113.86亿），盾安处于"成长期追赶者"定位，三花处于"全球垄断者"定位 [3][4]
- 盾安客户结构以中国自主品牌+二级供应商为主：已进入比亚迪、吉利、理想，并与银轮、拓普、法雷奥、腾龙、盛世达等系统/管路厂合作；三花直供特斯拉（Model 3热管理份额约70%独家）、大众、奔驰、宝马、沃尔沃、PSA、比亚迪等全球Tier-1定点 [2][6][8]
- 国内NEV热泵/集成模块市场：弗迪科技（比亚迪内部）+银轮股份+奥特佳三家合计份额>80%（高工智能汽车数据），三花在微通道换热器市占40%，盾安以零部件身份切入，尚未进入集成模块第一梯队 [银轮深度报告引用]
- 技术路线风险：CO2 (R744) 热泵需要耐高压专用阀类，单车电子膨胀阀价值量约600元，是普通热泵EXV（约300元）的2倍；大众 ID 系列已量产搭载，盾安 FBEV-C 产品已兼容 R134a 和 R744（-40℃至+165℃，6mm阀径），未构成颠覆威胁反而是单车价值量提升机会 [7]

## Deep Read Notes

### Source [1]: 2024年新能源热管理电子膨胀阀市场分析（产业在线）
Key data: 2024年中国NEV热管理EXV销量2700万只+，同比+46%；NEV热管理系统规模771亿元（内销676亿，+20%）；市场呈"二八分"（内销80%/外销20%）格局，2023-2024保持稳定
Key insight: 市场仍在高速扩容（CAGR~40%级别），三花、盾安、不二工机为三大HVAC背景龙头，海力达、翰昂从汽零背景切入。文章未披露具体个股份额数据
Useful for: 行业规模校验 + 验证盾安所在赛道仍处扩容期而非出清期

### Source [6]: 三花智控独霸热管理还有成长性吗（腾讯新闻/知乎）
Key data: 四通换向阀 CR3=98%；电子膨胀阀 CR3=96%；三花是特斯拉 Model 3 热管理零件独家供应商（份额~70%）；2020年三花NEV用EXV全球份额64.36%；三花汽零业务2023年99亿、2024年预计超113亿；手订单2023年85.22亿→2027年240亿（CAGR≈30%）
Key insight: 三花凭技术壁垒+客户粘性已锁定北美+欧洲主要新能源车平台；盾安难以从三花手中抢走特斯拉/欧洲客户，只能在中国自主品牌和二级系统厂中争取份额
Useful for: 量化三花市占率 + 验证三花-盾安差距属于结构性而非周期性

### Source [4]: 盾安环境2024年报点评（小牛行研/开源证券）
Key data: 汽车热管理2024营收8.12亿（+71.66%），其中大创并购增厚0.51亿；2024全年归母净利10.45亿（+41.58%）；综合毛利率18.22%（-4.34pct）；2024Q4资产减值冲回致盈利高增；NEV热管理2024年9月单月发货首次破亿，Q4达全年峰值
Key insight: 盾安NEV热管理增速（+72%）显著高于三花汽零（+20%左右）和行业均速（+46%），属于"低基数高弹性"追赶者；但毛利率远低于三花（27.64%），反映其处于定点爬坡+价格换量阶段
Useful for: 量化盾安第二曲线增速和毛利率差距（9pct结构性缺口）

### Source [7]: CO2热泵从1到N（新能源汽车热管理专题）
Key data: R744（CO2）热泵空调EXV单车价值约600元，普通热泵EXV约300元；需要耐高压阀类（阀体腔内多极磁性转子、泄压部件等设计）；大众 ID 系列已搭载；东风规划CO2直接式热泵+集成化设计路线
Key insight: CO2冷媒对阀类是价值量2倍提升而非颠覆——技术壁垒提高反而有利于三花、盾安等有深厚阀类积累的龙头；盾安 FBEV-C 已兼容R744说明已具备产品储备
Useful for: 判定技术路线风险为"中性偏利好"而非威胁；结论可直接服务红队论证
