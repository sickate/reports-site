## Findings

- 2024年全年营收126.78亿元(+11.39% YoY)，归母净利润10.45亿元(+41.58%)，净利率从2023年约7.2%提升至8.2%，盈利能力显著改善。[1]
- 2024年制冷配件营收96.12亿元(占75.8%)、制冷设备14.96亿元(占11.8%)、汽车热管理约8.1亿元(+72% YoY，占6.4%)。[1][8]
- 2024年制冷配件毛利率18.6%，制冷设备毛利率21.07%，制冷设备毛利率反而更高主要因订单结构优化。[1]
- 2025年上半年营收67.3亿元(+6.1%)，归母净利润5.4亿元(+12.9%)，冷配54.1亿(+8.8%)、汽零4.8亿(+81.8%)、设备4.8亿(-31.4%)，设备业务下滑拖累整体增长。[2]
- 2025H1主营业务收入构成：制冷空调零部件80.42%、制冷设备7.18%、新能源汽车热管理7.15%、其他5.25%，NEV热管理占比从2023年<2%快速提升至7%+。[2]
- 汽车热管理业务2022年收入2亿元(+290%)、2023年超4.5亿元(+125%)、2024年8.1亿元(+72%)、2025H1 4.8亿元(+81.8%)，呈现典型的S曲线高增长形态。[3][7][8]
- 2022年4月27日格力电器以约21.9亿元收购盾安精工所持29.48%股权入主，提供美的、格力双大客户协同后盾安在美的供应份额2023-2024年显著回升。[5][6]
- 全球制冷元器件龙头地位：截止阀全球市占率第一(2022前三季度约42.5%，2018年30.1%)、四通阀全球第二(约45.5%，2018年35.9%)、电子膨胀阀全球第二(约25.1%，2018年16.2%)。[7]
- 2022年中国电子膨胀阀市场份额：三花智控40.0%、不二工机26.8%、盾安环境26.2%，盾安稳居前三。[7]
- 汽车热管理客户已切入比亚迪、吉利、理想、华为问界/阿维塔，并与电池巨头宁德时代、热管理集成商银轮/拓普/法雷奥建立合作，产品以车用电子膨胀阀、电磁阀为主。[3][7]

## Deep Read Notes

### Source [1]: 盾安环境2024年年度报告摘要
Key data: 2024年营收126.78亿(+11.39%)，归母净利10.45亿(+41.58%)；制冷配件961,212万元(毛利率18.6%)、制冷设备149,553万元(毛利率21.07%)
Key insight: 制冷设备毛利率(21%)高于制冷配件(18.6%)，说明设备业务受益于特种订单(核电/数据中心/工业冷冻)，而非外界以为的低端业务；但2025H1设备业务-31.4%表明该业务波动大，订单型驱动
Useful for: 业务分部营收结构、毛利率对比、格力入主后净利率改善幅度量化

### Source [2]: 天风证券2025半年报点评
Key data: 2025H1营收67.3亿(+6.1%)，冷配54.1亿(+8.8%)、汽零4.8亿(+81.8%)、设备4.8亿(-31.4%)；主营构成冷配80.42%、设备7.18%、NEV热管理7.15%、其他5.25%
Key insight: 2025H1整体营收增速放缓至6.1%(vs 2024年+11.4%)，主因设备业务大幅下滑31%；若剔除设备拖累，冷配+汽零合计占比近88%且保持双位数增长；NEV热管理占比首次与设备业务持平，结构切换临界点到来
Useful for: 2025年最新营收结构、增长驱动拆分、第二增长曲线占比节点

### Source [7]: 申万宏源盾安环境深度报告-风起热管理
Key data: 四通阀市占率2018→2022前三季度 35.9%→45.5%，截止阀30.1%→42.5%，电子膨胀阀16.2%→25.1%；中国EXV市场三花40%/不二26.8%/盾安26.2%
Key insight: 盾安制冷配件市占率提升是结构性的(而非周期性)，2018-2022年四年间各主力阀件份额均提升10个百分点以上，说明其在格力入主前已通过技术和规模优势完成份额扩张；格力入主提供的是客户协同(美的+格力)而非产能/技术注入
Useful for: 市占率长期趋势、产品组合竞争力、结构vs周期增长拆分

### Source [3]: 证券时报2024H1业绩点评
Key data: 2024H1营收63.46亿(+13.87%)，制冷配件49.74亿(+15.74%)、制冷设备7.05亿(+2.91%)、汽车热管理2.65亿(+93.22%)
Key insight: 汽车热管理客户已覆盖比亚迪/吉利/理想/华为系(问界阿维塔)，并与银轮、拓普、法雷奥等集成商+宁德时代电池厂建立B端合作，表明盾安的打法是做Tier 2组件供应商而非Tier 1集成商，规避与三花智控的直接竞争
Useful for: NEV客户名单、产品路线(EXV/电磁阀为主)、渗透率提升的结构性论据

### Source [5]+[6]: 格力入主背景
Key data: 2022年4月27日股权过户完成，格力收购29.48%股权(约21.9亿元)；2022年营收101.44亿(+3.12%)，扣非净利4.61亿(+21.48%)
Key insight: 格力入主前盾安因债务重整(原大股东盾安精工质押爆仓)经营承压，格力提供供应链稳定性和大客户协同；入主后2023-2024年在美的份额也回升(未因格力并购而被美的抛弃)，说明盾安的产品力决定了客户粘性
Useful for: 治理变化时间线、格力并购逻辑、同业客户关系验证

## 增长点拆分（周期性 vs 结构性）

**结构性贡献（主导，占增长约70%）：**
- NEV热管理业务2022→2024年从2亿增至8.1亿(+305%)，贡献约6亿增量
- 制冷配件市占率从2018年约30%提升至2022年42%+，份额扩张带来的收入增长

**周期性贡献（次要，约30%）：**
- 2024年家电"以旧换新"补贴带动空调产业链排产，制冷配件增速从2023年的个位数回升至15%+
- 铜价2023-2024年从6万/吨升至7万+，带来被动的ASP提升(成本加成定价)
