## Findings

- **2024 Top-5 客户集中度**: 前五名客户销售额合计 **56.85亿元**，占年度营业收入的 **44.84%**；其中第一大客户贡献 **24.77亿元（占比19.54%）**，第二 16.17亿（12.75%），第三 6.22亿（4.90%），第四 4.96亿（3.91%），第五 4.74亿（3.74%） [1][3]。
- **2023 对比**: 2023年前五名客户销售合计 **48.61亿元**，占比 **42.70%**；集中度比2024年略低约2个百分点，显示2024年对大客户的依赖度进一步上升 [2]。
- **格力关联交易规模**: 2024年 盾安环境 与控股股东格力电器及其下属公司的 **日常关联交易预计上限为 32亿元（320,000万元）**；**2024年上半年实际发生 142,005.59 万元（约14.2亿）**；若按上半年节奏年化并结合第一大客户24.77亿规模，可推断格力是 2024年第一大客户且全年关联交易实际发生额大致在 24-28亿级别 [1][5]。
- **关联交易类型**: 以双向交易为主——盾安向格力销售制冷配件（截止阀、四通阀、电子膨胀阀、换热器、两器）；同时向格力系统采购部分原材料和金融服务；控股股东2022年通过协议转让+定增累计出资约30亿取得38.46%股权 [1][9]。
- **格力入主前后客户结构变化**: 格力入主前（2021）第一大客户销售约 14.53亿元（占比14.77%）；格力入主后2024年第一大客户达 24.77亿元（占比19.54%），**绝对额+70% / 占比+4.8pct**，证实"格力转单"效应 [1][7]。
- **美的客户现状**: 根据2025Q3点评"**格力持续转单，美的订单回升**"。美的在2022-2023年因盾安被格力控股一度减少订单，2024年起重新回升，但第二大客户（美的系）占比12.75%仍明显低于格力 [7][1]。
- **2024 前五名供应商集中度**: 前五名供应商采购额合计 **35.45亿元**，占年度采购总额 **36.46%**；第一大供应商 10.49亿元（10.78%）。供应商集中度明显低于客户集中度（36.46% vs 44.84%），采购侧议价权相对分散 [1]。
- **原材料成本敏感度**: 主要原材料为 **铜、铝、锌** 等有色金属；2024年 **直接材料成本占主营业务成本 75.49%**；2024年综合毛利率 **18.22%（同比-4.34pct）**，制冷配件分部毛利率 21.07%（2023年为约20.03%，2022年为14.59%回升至2023年24.70%）——显示铜价上涨直接压缩了配件板块毛利 [1][2][6]。
- **套期保值与对冲**: 2025年8月董事会审议通过《关于开展商品套期保值业务的可行性分析报告》，公司明确将通过 **联动定价机制+期货套保+商务谈判** 缓冲原材料波动，间接确认铜铝价格是主要毛利风险源 [9]。
- **治理风险评估**: (a) Top1客户占比19.54%，叠加为控股股东（关联方），存在"单一买家+控股股东"双重集中；(b) 前五大客户占比45%，虽未超50%监管红线，但较2023年提升；(c) 美的等非格力系客户议价权下降，订单波动大（2022收缩→2024回升）；(d) 应收账款对利润比高达 223.3%，存在潜在回款与关联方信用敞口 [1][6][7]。

## Deep Read Notes

### Source [1]: 盾安环境2024年年度报告（新浪财经转载全文）
Key data:
- 营业总收入 126.78亿；归母净利润 10.45亿（+41.58%）
- 前五大客户 56.85 / 24.77 / 16.17 / 6.22 / 4.96 / 4.74 亿元
- 前五大供应商 35.45亿（36.46%），Top1 10.49亿
- 制冷配件毛利率 21.07%，综合毛利率 18.22%
- 直接材料占主营成本 75.49%
Key insight: 第一大客户销售24.77亿恰好等于2024H1与格力关联交易14.2亿的约1.75倍（考虑下半年基数更大），高度吻合，可视为"第一大客户=格力"的默认假设。
Useful for: Top5客户占比、格力依赖度、毛利率基数

### Source [5]: 2024年半年度报告（关联交易章节）
Key data: 2024H1 盾安环境与格力电器及其下属公司实际发生日常关联交易 **142,005.59万元**（约14.2亿）
Key insight: 同期营业收入约63亿左右，则关联交易占半年营收~22%，是典型"依赖型关联方"。
Useful for: 推断全年格力关联交易规模约 24-28亿区间

### Source [2]: 2023年年度报告
Key data: 前五名客户 48.61亿 / 占比42.70%；前五大供应商 27.47亿 / 占比33.42%；制冷配件毛利率 24.70%（同比+10pct，因成本下降+格力转单放量）
Key insight: 2023年毛利率处于近年高点，2024年因铜价大涨已回落近4pct——敏感度明显。
Useful for: 纵向比较客户集中度与毛利率走势

### Source [7]: 新浪财经2025三季度综评
Key data: 2025前三季度 营收97.23亿、净利7.58亿；分部结构 冷配80.42% + 设备7.18% + NEV热管理7.15%；毛利率 17.91%
Key insight: "格力持续转单，美的订单回升" 这一定性判断与2024年第一大客户绝对额+70%的财报数据互相印证。
Useful for: 客户结构演化定性描述

### Source [9]: 格力集团财务公司风险持续评估报告（2025-08）
Key data: 控股股东仍为格力电器（持股 38.46%）；存贷款关联交易在财务公司进行；公司同步审议商品套期保值方案
Key insight: 金融服务类关联交易叠加商品关联交易，构成多层次关联敞口；套保议案从侧面确认铜铝风险敞口之大。
Useful for: 关联交易广度、原材料风险管理手段
