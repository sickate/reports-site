# 当光改写世界：艺术赏析页面

页面：`/reports/2026-10-art-of-light`。首页“艺术赏析”分组注册在 `src/reports/index.js`；React 路由复用现有报告加载机制。

## 文件与维护

- `index.jsx`：双画首屏、四组比较、偏好地图、氛围筛选画廊、原生 dialog 放大。
- `style.css`：仅作用于 `.art-light` 与 `al-` 前缀，沿用站点深蓝主题。
- `content.js`：中文赏析、比较数据与馆方/书信资料链接。
- `artworks.json`：每幅画的作者、准确版本、年代、馆藏、作品记录、复制图来源、下载URL、权利声明、尺寸和站内图片路径。
- `public/images/art-of-light/`：17 张优化 JPEG。本地随项目发布，不调用第三方图片API，不使用聊天引用。

更新图片时，先核验作品版本、图像文件页许可和是否为忠实二维复制图。只等比例缩小与压缩，不调色；更新元数据尺寸，保留作者、馆藏与图像发布者标注。图库组件以原比例呈现，不裁切作品。

## 编辑边界

馆藏事实与赏析应分开。比较并不判定统一排名；个人偏好只是根据本次讨论的可修正推断。

- 梵高伦敦《向日葵》为1888年；莫奈《向日葵花束》为1881年。
- 《星月夜》为1889年6月MoMA作品，不能混用1888《罗讷河上的星夜》。旋涡无法直接证明某种幻觉或诊断。
- 透纳《现代罗马》为1839年英国浪漫主义作品。不能标成印象派。
- 《诺勒姆城堡，日出》保留“约1845”；《暴风雪》1842为展出年代。
- 《议会大厦大火》使用Cleveland 1942.647版本，创作年代1835，标题1834指事件日期。
- 蒙蒂切利《花瓶里的花》约1875；厚涂影响有梵高书信689支持，但不自动决定艺术价值。
- 广重展示的是Brooklyn 30.1478.30印本，与梵高持有的VGM n0077V1962是同一设计的不同印本；不能声称展示的这张就是他的描摹原件。
- Commons PD-Art/PDM与馆方CC0分开标注。部分原馆图像有不同发布条件，不把Commons许可写成馆方授权。

资料核验：2026-10-14。Tate《暴风雪》《诺勒姆》主站对自动请求403，身份/年代用Tate官方开放数据（2014快照）与Getty/Tate展览资料交叉核验，不据此推断当前展厅或展出状态。
