# 锂价自动采集与历史换算

适用页面：`2026-06-metals-ytd`。核验日期：2026-10-13。

锂已从固定的 22,000 USD/吨改为 **Mysteel 中国电池级碳酸锂早盘现货价格**，规格为 **Li₂CO₃≥99.5%**。首次回填得到 **280 个实际报价日**，覆盖 2025-08-19 至 2026-10-13。原始单位为人民币/吨，页面继续以 USD/吨显示，并同时列出人民币原价和汇率日期。

## 产品与来源

采用 [Mysteel 碳酸锂现货公开图表](https://www.mysteel.com/mmlc/)中的“电池级碳酸锂（早盘）”。公开页面同时列出优质电池级（≥99.6%）、工业级（≥99.2%）、现货指数、晚盘报价与期货升贴水；这些项目都不与所选早盘现货序列拼接。日线来自该页面自行调用的公开历史图表接口，指标为 `ID01551919`，不是广期所期货主力连续合约。

适配器同时校验指标代码、中文产品名、纯度、地区、早盘标签和“元/吨”单位。返回值定义发生变化时退出并保留已有数据。JSONP 包装只解析为 JSON，不执行远端脚本。没有使用登录信息或绕过访问限制。

原来的人工值称为 SMM 中国价格，而本次来源是 Mysteel，因此新序列使用独立标识 `mysteel-china-battery-carbonate-am-usd`。YTD 基准从同一来源历史取得，旧的 18,000 USD/吨年末点与 22,000 USD/吨人工快照均不进入新序列。50 年年度文件和另一个全球锂报告的期限结构数据保持独立。

## 历史汇率

汇率使用 [Frankfurter 的 ECB 来源](https://frankfurter.dev/providers/ecb/)，请求明确指定 `providers=ECB`，不采用平台默认的多来源混合率。接口按日期返回 `USD → CNY`，即每美元对应多少人民币。[接口说明](https://frankfurter.dev/)

美元价格 = 人民币价格 ÷ 当时的 USD/CNY，结果四舍五入至两位小数。对每个报价日，选择当天或此前最近公布的 ECB 汇率；不使用未来日期汇率，也不把当前汇率套到整段历史。不同地区的节假日日历不一致，最近可用汇率最多允许相差 7 天；超过这个范围或汇率请求失败时，整批不写入。

2026-10-13 的早盘原价为 **107,250 CNY/吨**。采集时 ECB 最近汇率日期为 **2026-10-12**，`1 USD = 6.6928 CNY`，对应 **16,024.68 USD/吨**。同来源 2025-12-31 为 **117,250 CNY/吨**，按当日 `7.0010` 换算为 **16,747.61 USD/吨**，因此本页美元 YTD 约为 **−4.3%**。这些美元值和涨幅是本项目换算结果，包含人民币汇率变化，不应当作人民币现货自身的涨幅。

早盘时间固定在北京时间 10:20；在这个时间之前只读取此前报价日。当天 ECB 汇率可能尚未发布，页面会明确显示实际使用的前一汇率日。后续增量采集会重读近 14 天数据，因此当当天参考汇率公布或历史报价修正时，美元换算可随之更新，原价和来源日期仍然保留。

## 存储与运行

每个观察点保存 `date`、`price`、`nativePrice`、`nativeUnit`、`usdCny`、`fxDate`、`sourceUrl` 和 `fxSourceUrl`。`date` 是来源给出的报价日期，而不是采集日期。缺失日期不插值，不填零，也不把昨日值伪装成今天值。

```bash
# 仅回填锂的420天历史
node scripts/backfill-lithium.mjs

# 仅更新锂，适用于核验或手动增量采集
METALS=lithium node scripts/update-prices.js

# 定时更新所有金属时自动包含锂与钨
node scripts/update-prices.js
```

`DATA_FILE` 与 `DAILY_FILE` 继续支持服务器路径。现有小时 cron 无需新增任务；发布更新后的脚本和来源模块、执行历史回填后生效。部署脚本同步 `backfill-lithium.mjs` 与来源库，先执行铜、钨、锂的专用回填和增量核验，再发布页面，保留服务器日价、年度文件和发布备份。全金属回填也已识别锂的独立基准，不会再为它添加旧年度锚点或人工快照。

行情或汇率失败、单位/规格变化、日期与价格长度不一致、冲突报价均会报错，之前的锂序列保持原样，不回退到旧固定值。来源链接指向公开价格页，汇率链接指向 ECB 来源说明；没有将当前指数、优质电池级或工业级价格作为备用值自动混入。

## 验证与限制

11 项锂价测试与 10 项原钨价测试通过，覆盖产品/纯度/时段混用、JSONP 非执行解析、日期价格对齐、历史汇率方向、禁止未来汇率、异常与缺失汇率、失败不写入、基准迁移和重复运行。实际历史采集获得 280 点，回填前后其他 12 种金属（包括钨）逐节点比较一致。

公开图表接口没有向本项目承诺服务可用性或持久版本；若网站更改代码或访问方式，应重新核对规格，再修改适配器。现货报价属于 Mysteel 的市场价格口径，不是交易所成交收盘价。来源税费、品牌、货量等更详细评估规则未在本次接口中逐项核验，页面只标注已证实的地区、品位和早盘现货属性。
